# Icon Mode

Select and print icons from the 7000+ Material Design Icons library. Designed for labeling smart switches, devices, and controls.

## Selecting Icons

1. Use the **search bar** to filter icons by name
2. Click icons to **toggle selection** (blue highlight + checkmark)
3. The counter shows how many icons are selected
4. Click **Clear selection** to deselect all

The icon grid loads in pages of 100, with infinite scroll for more.

## Layout Settings

| Setting | Range | Default | Description |
|---------|-------|---------|-------------|
| Icon Size | Small (24px) to XXXL (128px) | Medium (32px) | Size of each icon |
| Columns | 2-8 | 4 | Icons per row in the print output |
| Spacing | 4px-32px | 16px | Gap between icons (cutting guides) |

## Arrange Icons (Drag & Drop)

Below the settings, the **Arrange Icons** section shows a visual grid matching the print layout. Drag any icon to a different position to reorder them. The print preview updates automatically.

## Saved Icon Sets

Save frequently-used icon combinations for quick access:

1. Select your icons and configure size/columns/spacing
2. Click **Save Current** and enter a name
3. The set appears as a pill-shaped button
4. Click any saved set to load it instantly
5. Hover and click the X to delete a set

Sets are stored in the browser's localStorage and persist across sessions. Each set saves: icons, size, columns, and spacing.

## Print Output

Icons are printed in a grid with **dotted cutting guides** between cells, making it easy to cut individual icons for labeling.
